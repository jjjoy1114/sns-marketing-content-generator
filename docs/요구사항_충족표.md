## 7. 과제 목표 — "스스로 설명할 수 있어야 하는" 6가지

| # | 목표 | 학습 근거 (구현 과정) |
|:---:|---|---|
| 1 | HTML/CSS/JS의 역할 | 화면(HTML)·디자인(CSS)·동작(JS)을 파일로 분리해 직접 구현 |
| 2 | 입력→요청(fetch)→응답 화면 반영 흐름 | `app.js`에서 입력 수집→`fetch('/api/generate')`→결과 표시 구현 |
| 3 | Vercel Serverless Functions·프론트→백엔드(Python) 호출 구조 | `api/generate.py` 서버리스 함수 작성·호출 |
| 4 | 환경 변수로 API 키를 안전하게 관리하는 이유 | `.env`·Vercel 환경변수로만 관리, 키 노출 방지·폐기·재발급 경험 |
| 5 | 로컬 vs 배포 환경 차이 및 재배포 흐름 | 로컬(localhost)·배포(vercel.app) 차이 이해, push→자동 재배포 경험 |
| 6 | AI 생성 코드의 오류 원인 파악·수정 | 키 형식(AQ.)·모델명·CSS 특정성 오류를 직접 원인 분석·수정 |
